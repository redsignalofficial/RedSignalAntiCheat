# RedSignalAntiCheat

RSAC and customizable Minecraft anti-cheat designed to detect common hacks across multiple server versions with Folia, Paper, and Spigot compatibility.

## Authors & Contributors
- **redsignalofficial** ([@redsignalofficial](https://github.com/redsignalofficial))
- **RinDevelopment** ([@RinDevelopment](https://github.com/RinDevelopment))

## Features
- **Movement Checks**: Flight, Speed, Jump, NoFall, LiquidWalk, FastClimb, NoSlow, Step, BoatFly, Elytra, and Trident boosts.
- **Combat Checks**: KillAura, Reach, Criticals, AutoClicker, and Velocity knockback analysis.
- **Interaction Checks**: FastPlace, BlockPlace/Break reach and rotation, FastBreak, GhostBreak, and Scaffold.
- **Packet Checks**: MorePackets, Timer, and protocol anomaly detections via custom packet injection (`RSInjector`).
- **Compatibility**: Spigot, Paper, Folia, Geyser, Floodgate, and popular gameplay plugins.
